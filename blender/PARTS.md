# ta-radio 無線機モデルの部品表

手に持つ業務用の無線機（`ta_radio`）。動く部品は無い静的な prop。anymachine の手順のうち「部品表を先に決める → 1 本のスクリプトで組む → 検証で締める」を使う。参照画像の生成（外部の有料サービス）は使わず、純正の `prop_cs_hand_radio`（mm_radio が手に持たせていたもの）を読み込んで測った値を参照にした。

## 軸・原点

純正の `prop_cs_hand_radio` と同じにする。こうすると mm_radio が使っていた手への付け方（右手の骨 57005、位置 `0.14, 0.01, -0.02`、回転 `110, 120, -15`）をそのまま使える。

| 項目 | 純正（測った値） | ta_radio |
| --- | --- | --- |
| 正面（画面・スピーカー） | -Y | -Y |
| 上 | +Z | +Z |
| 原点 | 本体の中、上から 5 cm ほど | 同じ |
| 本体の幅 X | -0.037〜0.037 | -0.031〜0.031 |
| 本体の奥行き Y | -0.018〜0.020（背面のクリップ込みで 0.031） | -0.017〜0.017（電池 0.022、クリップ 0.028） |
| 本体の高さ Z | -0.127〜0.050 | -0.122〜0.040 |
| アンテナ | 左上 x=-0.023、細い棒で z=0.306 まで | 左上 x=-0.017、太く短いゴムのアンテナで z=0.135 まで |
| 送信ボタン（PTT） | +X の側面、z=-0.03〜0.01 | +X の側面、z=-0.040〜0.012 |

## 上限

- 三角形は 2,000 まで（手に持つ小物。純正は 440）
- 寸法の誤差は 1 mm まで（ビルドの終わりに、部品表の外形と比べて表示する）
- テクスチャは 512×512 の 1 枚（DXT1）

## 検証

- 書き出した ydr を空の場面に読み込み直し、メッシュの数・三角形の数・外形が書き出す前と同じか比べる
- 正面・側面・斜め・背面を描画して目で見る
- ox_inventory のアイコン（`install/radio.png`）も同じモデルから描画する
